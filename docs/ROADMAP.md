# План разработки: личное фитнес-приложение

Порядок этапов MVP по ТЗ (`docs/ТЗ.md`). Сначала данные, потом экраны: каждый следующий этап опирается на предыдущий. Самый важный этап — 5, режим тренировки. Ради него всё и делается.

Оценки времени указаны для вечерней работы одного разработчика. Весь MVP займёт около 2–3 недель.

## Этап 0. Подготовка (1 вечер)

- [x] Утвердить ТЗ. Решение: синхронизация в MVP не нужна, остаётся в v3
- [x] `git init`, `.gitignore`, первый коммит

- [x] Подключить линтер (oxlint, идёт в шаблоне Vite вместо ESLint), Prettier, Vitest
- [x] Подготовить деплой на GitHub Pages: `.github/workflows/deploy.yml` (lint → typecheck → test → build → публикация)
- [ ] Создать репозиторий на GitHub, запушить, включить Pages (Settings → Pages → Source: GitHub Actions)
- [ ] Открыть ссылку на телефоне и убедиться, что заглушка отображается

**Результат:** пустое приложение открывается на телефоне по ссылке.

## Этап 1. Модель данных и хранилище (2 вечера)

- [x] `src/domain/types.ts`: типы Exercise, Program, ProgramDay, Workout, WorkoutEntry, Set (ТЗ, раздел 3); у всех сущностей поля `id` (UUID), `updatedAt`, `deletedAt`
- [x] `src/data/db.ts`: схема Dexie с таблицами exercises, programs, workouts (с индексом `*exerciseIds`) и meta
  - [x] `src/data/repositories/`: функции чтения и записи для каждой таблицы
- [x] `src/data/seed.ts`: стартовый набор из ~30 упражнений, загружается при первом запуске
- [x] `src/domain/metrics.ts`: 1ПМ (Эпли), тоннаж, личные рекорды, тоннаж по неделям
- [x] Тесты для `metrics.ts` и репозиториев (fake-indexeddb): 28 тестов

**Результат:** данные сохраняются и читаются, расчёты покрыты тестами. Экранов пока нет.

- [x] Роутинг (адреса через #, чтобы работало на GitHub Pages) и нижняя панель на 4 вкладки: Сегодня, Программы, История, Прогресс

**Результат:** между вкладками можно переключаться, пока на них заглушки.

## Этап 3. Справочник упражнений (1 вечер)

- [x] Список упражнений с поиском (без учёта регистра и «ё») и фильтром по группе мышц; поиск закреплён наверху
- [x] Добавление, редактирование и удаление упражнений (удаление с подтверждением, защита от дубликатов названий)
- [x] Компонент выбора упражнения (`ExercisePicker`) с созданием нового прямо из поиска; пригодится на этапах 4 и 5

**Результат:** справочник работает, упражнение можно выбрать из шторки.

## Этап 4. Программы (2 вечера)

- [x] Список программ, создание, копирование, удаление (с подтверждением)
- [x] Редактор дней: название, упражнения в нужном порядке, подходы, повторения (от–до), вес, отдых; сохраняется сам
  - [x] Перестановка упражнений и дней вверх и вниз, копирование дня
- [x] Выбор активной программы и указатель «следующий день» в таблице meta; план следующего дня на экране «Сегодня»

**Результат:** программу из 3 дней по 5 упражнений можно собрать меньше чем за 5 минут.

## Этап 5. Режим тренировки (3–4 вечера, главный этап)

- [x] Старт из дня программы (следующего или любого другого) или свободная тренировка без плана
- [x] План копируется в Workout, веса и повторения подставляются из прошлой тренировки
- [x] Строки подходов: кнопки ±шаг веса и ±1 повторение, отметка «выполнено» одним касанием; новый вес подтягивает следующие подходы
- [x] Результат прошлого раза показывается у каждого упражнения
- [x] Таймер отдыха по метке `restEndsAt`: звук в конце, вибрация на Android, ±15 с, «Готов»
- [x] Автосохранение после каждого действия (ввод с задержкой ~500 мс), тренировка переживает перезагрузку страницы
- [x] Добавление и удаление подхода или упражнения на ходу, заметка к тренировке
- [x] Экран не гаснет (Wake Lock)
- [x] «Завершить» показывает сводку: время, тоннаж, новые рекорды; указатель дня сдвигается на следующий
- [x] Экран «Сегодня»: следующий день программы, кнопка «Начать», баннер незавершённой тренировки

**Результат:** с приложением можно провести реальную тренировку в зале. Здесь нужно проверить критерии приёмки 2–5.

## Этап 6. История (1 вечер)

- [x] Список тренировок по месяцам: дата, название, длительность, тоннаж
- [x] Просмотр деталей тренировки: время, подходы, тоннаж, рекорды того дня
- [x] Редактирование (через экран тренировки: вес, повторы, подходы, упражнения, дата, заметка) и удаление с подтверждением

**Результат:** все прошедшие тренировки видны, ошибки в них можно исправить.

## Этап 7. Прогресс (2 вечера)

- [x] Выбор упражнения (по частоте), график лучшего веса и расчётного 1ПМ по тренировкам с подсказкой по касанию
- [x] Личные рекорды: максимальный вес, максимальный 1ПМ, лучший подход (для собственного веса — повторы, для времени — секунды)
- [x] Таблица последних подходов
- [x] Тоннаж по неделям, тренировки за 7 и 30 дней; короткая статистика на экране «Сегодня»

**Результат:** прогресс виден на графиках (критерий 6).

## Этап 8. Резервная копия и релиз MVP (1–2 вечера)

- [x] Экспорт всех данных в JSON-файл с полем `version`, импорт из файла с проверкой и подтверждением; удаление всех данных
- [x] Манифест PWA и иконки, установка на главный экран; service worker для работы без интернета (перенесён из v2: в зале часто нет сети)
- [x] Запрос `navigator.storage.persist()`, раз в неделю напоминание про экспорт на экране «Сегодня»
- [x] Экран «Настройки» (кнопка в верхней панели): шаг веса, резервная копия, установка, защита данных
- [ ] Пройти все 8 критериев приёмки на своём телефоне (автоматически проверены — см. ниже)
- [ ] Деплой на HTTPS, установить приложение на телефон и начать им пользоваться — нужен репозиторий на GitHub

**Критерии приёмки (ТЗ, раздел 8), автоматическая проверка:**

| # | Критерий | Как проверено |
| --- | --- | --- |
| 1 | Программа 3 × 5 упражнений меньше чем за 5 минут | не замерено; по устройству экрана ~3 касания на упражнение, ≈50 касаний на программу |
| 2 | Подход отмечается одним касанием | тест `workout-screen`: одно касание по номеру подхода |
| 3 | После отметки запускается таймер отдыха с сигналом | тесты `workout`, `workout-screen` |
| 4 | Перезагрузка посреди тренировки не теряет подходы | тест «незавершённая тренировка переживает перезапуск» |
| 5 | Следующая тренировка подставляет веса из прошлой | тесты `data`, `workout-screen` |
| 6 | График показывает лучший вес и 1ПМ по датам | тест `progress-screen`, скриншоты |
| 7 | Экспорт → очистка → импорт без потерь | тест `backup`: сравнение всех таблиц до и после |
| 8 | На 360 px нет горизонтальной прокрутки | скриншоты каждого этапа на 360 px |

**Результат:** MVP готов, приложение на телефоне.
