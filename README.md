# Фитнес-приложение

Личное мобильное приложение (PWA): программы тренировок, подходы, повторения, веса, прогресс.

## Структура

```
fitnes/
  docs/        документация: ТЗ (md и docx), план разработки
  frontend/    само приложение: React + TypeScript + Vite, данные в IndexedDB
    src/
      app/          роутинг, нижняя панель, тема
      screens/      экраны: Сегодня, Программы, Тренировка, История, Прогресс
      components/   переиспользуемые компоненты
      domain/       типы и расчёты (1ПМ, тоннаж, рекорды)
      data/         база Dexie, репозитории, стартовые данные, экспорт/импорт
      store/        состояние активной тренировки и таймера
      sync/         адаптер синхронизации (v3)
    public/       иконки, манифест PWA
    tests/        тесты Vitest
    prototype/    черновой прототип на одном HTML (для справки)
  backend/     серверная часть, появится только в v3 (Supabase)
```

План и статус: [docs/ROADMAP.md](docs/ROADMAP.md). Команды разработки: [frontend/README.md](frontend/README.md).
